## Interpretation

Eurostat uses prc_hicp_minr / coicop18=TOTAL after the ECOICOP2 migration. EA20 is kept fixed, not silently combined with EA21. These are current histories, not recovered original releases. FRED public CSV is not an ALFRED vintage archive. CFTC report dates must not be treated as publication timestamps.

BLS limits: https://www.bls.gov/developers/api_FAQs.htm ; Eurostat migration: https://ec.europa.eu/eurostat/web/hicp/information-data

## Remaining M0 work

For each series: earliest usable history, original releases, revisions, exact availability, quotas and licensing. TE consensus/PIT entitled coverage and actual price remain unverified. No synthetic consensus is permitted. Metadata depth is not proven usable history. The older Dukascopy binary endpoint returned 429 with migration guidance; the measured JSON API is used instead.
