## Verified documentation

- ECB daily reference rate is published for information, usually around 16:00 CET; it is not an executable trading price: https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html
- Trading Economics documents PIT endpoints, but entitled history and fixed price have not been established: https://docs.tradingeconomics.com/economic_calendar/point-in-time/ ; https://tradingeconomics.com/analytics/api.aspx
- API limits for unregistered/registered BLS access: https://www.bls.gov/developers/api_faqs.htm
