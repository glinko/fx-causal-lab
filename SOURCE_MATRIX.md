## Interpretation

Eurostat uses prc_hicp_minr / coicop18=TOTAL after the ECOICOP2 migration. EA20 is kept fixed, not silently combined with EA21. These are current histories, not recovered original releases. FRED public CSV is not an ALFRED vintage archive. CFTC report dates are display/observation dates only; features use `available_at`, never the report date.

BLS limits: https://www.bls.gov/developers/api_FAQs.htm ; Eurostat migration: https://ec.europa.eu/eurostat/web/hicp/information-data
