Anti-leakage правила

  • target_start_at >= prediction_time проверяется для каждой строки.
  • Actual недоступен для pre_event. Для остальных режимов требуется event_available_at <= prediction_time.
  • Неполная D1-сессия делает этот и все более дальние горизонты недоступными; пропуск не сжимается.
  • Отсутствующее будущее окно остаётся null.
